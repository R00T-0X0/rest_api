
# REST API

A simple PHP project for handling HTTP requests using REST API principles.

## Features
- Supports GET, POST, PUT, and DELETE methods.
- Reads HTTP request headers.
- Handles JSON request bodies.
- Returns JSON responses.
- Uses appropriate HTTP status codes.
- Handles invalid JSON input.
- Supports Authorization headers.

## Technologies
- PHP
- HTML
- CSS
- JavaScript

## How to Run
1. Place the project inside the XAMPP `htdocs` folder.
2. Start Apache.
3. Open `http://localhost/rest_api/` in your browser.

## Purpose
Created to practice REST API development and HTTP request handling.
